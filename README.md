# 保護継電器 動作シミュレータ

保護継電器の動きをアニメーションで確かめる講義教材です。ブラウザで開くだけで動きます（1 枚の HTML、ライブラリなし）。

**https://lutelute.github.io/protection-relay-sim/**

## 中身

- **継電器ごとの動作**：OCR・OCGR・OVR・OVGR・UVR・DSR・DGR・DFR・RDFR・DR・FR・RPR の 12 種。結線図・特性図・判定ロジック図・オシログラフ風の記録で、事故の検出からトリップ、遮断までを追う。正動作・不動作・不要動作のシナリオ付き。数式には、記号の意味・言葉での説明・いまの整定値を入れた計算を付けた。位相の図は基準を止めて描き、整定値の円と動作域を重ねる（「ベクトルを回す」で回転も見られる）。
- **単線結線図で見る（工場の高圧受電設備）**：6.6 kV の受電設備で事故を起こし、%Z 法（基準 10 MVA）で求めた事故電流と、MCCB・受電 OCR・PAS（SO・DGR）・変電所の F51/F67G・自家発の OVGR/UVR の時限協調を見る。
- **単線結線図（送電線と変電所）**：66 kV 送電線・配電用変電所（66/6.6 kV）・6.6 kV 配電線で事故を起こし、87L・44S（第 1〜3 段）・67G・T87・96・TP51・TS51・64B・F51・F67G の主保護と後備を見る。保護区間の帯と、事故の場所ごとの動作時間の階段図（いちばん下の線が主保護）。変圧器の層間短絡、励磁突入（第 2 高調波抑制）、遮断器の不動作、整定ミス、高抵抗地絡、再閉路とロックアウトのシナリオ付き。
- **正動作なら・経過から飛ぶ**：両方の単線結線図で、選んだ事故で動くべき装置（主保護・後備・動いてはいけない装置）といまの整定での動作時間を示し、実際の動きと比べて判定する。事故の経過の行を押すと、その時刻へ戻って止まる。継電器のタブでも、経過の札やオシログラフを押すとその時刻へ飛ぶ。
- **抜け穴と組み合わせ**：継電器ごとに、特性の形の理由（その領域は不要動作を避けるためか、協調のためか、物理的に見えないのか）と、検出できない事故（事故抵抗・接地抵抗・雷・INV など）を整理。事故の種類 × 装置のカバー表と、設置の組み合わせの例。
- **モデル化と解析**：見たい時間で解析の方法が決まる「時間の地図」と、発電機（X''d・X'd・Xd、動揺方程式）・負荷（ZIP、電動機）・線路（R を無視した誤差、地絡の C）・INV（事故電流の頭打ち、慣性、FRT）を動かして確かめる図。%Z 法の例題、計算の手順とツール。
- **器具番号**：JEM 1090 の器具番号表と、補助記号・保護対象の英字の組み立て。

## 注意

整定値・動作時間はアニメーション用の代表例です。実機の整定は保護協調計算で決めてください。継電器は瞬時復帰、波形は概念図、再閉路の時間は縮めて表示しています（前提はページ内の「計算の前提」に書いています）。
